# Contributing

Thank you for your interest in Baidu Ping Booster.

1. Open an issue describing the bug or proposed improvement.
2. Fork the repository and create a focused branch.
3. Follow WordPress coding, escaping, sanitization, nonce, and capability-check practices.
4. Test on a non-production WordPress installation with supported PHP and WordPress versions.
5. Submit a pull request with a clear summary and testing notes.

Do not include API tokens, exported settings, credentials, logs containing private data, generated archives, or vendor directories.

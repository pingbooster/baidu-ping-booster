# Security Policy

## Supported version

Security fixes are applied to the current public release of Baidu Ping Booster.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to **support@pingbooster.site**.

Include a clear description, affected version, reproduction steps, and potential impact. Please do not open a public issue until PingBooster has had a reasonable opportunity to investigate.

Never send Baidu API tokens, exported settings, database contents, customer information, credentials, private keys, or other sensitive production data.
